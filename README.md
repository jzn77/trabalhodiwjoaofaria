# Acervo — Gerenciamento de Livros

Sistema web acadêmico para gerenciar os livros de uma biblioteca.

> **Etapa 1 — HTML e Estrutura da Interface.** Nesta etapa existe apenas a estrutura visual da aplicação. Nenhuma funcionalidade em JavaScript foi implementada ainda: botões, pesquisa, filtros, ordenação, edição e exclusão aparecem na tela, mas ainda não executam ações.

## Descrição

O **Acervo** permite (nas próximas etapas) cadastrar, consultar, pesquisar, filtrar, ordenar, editar e excluir livros de uma biblioteca. A entidade principal do sistema é o **livro**.

## Objetivo

Construir a estrutura inicial da interface utilizando **HTML semântico**, já prevendo os elementos necessários para as funcionalidades que serão implementadas futuramente. Os dados exibidos são fictícios e estão escritos diretamente no HTML.

## Tecnologias utilizadas

- HTML5 (semântico)
- CSS3 (escrito manualmente, sem frameworks)
- JavaScript (arquivo criado e referenciado, ainda sem lógica)
- Git e GitHub
- GitHub Pages

## Estrutura do projeto

```text
acervo/

├── README.md
├── pages/
│   └── detalhes.html     # Página de detalhes de um livro
└── assets/

    ├── js/
    │   └── script.js     # Reservado para as próximas etapas

```
